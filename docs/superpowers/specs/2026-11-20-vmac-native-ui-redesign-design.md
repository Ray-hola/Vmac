# VMac 界面重做：设计说明

日期：2026-11-20　分支：`ui-native-blue`

## 1. 目标

VMac 的初衷是让虚拟机用起来像本机的一个原生 App：就像在同一台电脑上操作，而不是在操作一个「虚拟机管理工具」。这次重做按这个初衷来组织全部界面。

设计要同时满足四点：

1. **客机是主角。** 打开 VMac 看到的就是客机画面，管理界面平时不占地方。
2. **蓝、白、黑。** 采用 DeepSeek 的配色：白底、黑字、一种蓝色做强调。只有这一套浅色，不做深色。
3. **干净、有质感。** 元素少，对齐严格，留白充足，层级靠字重和间距区分，不靠边框和阴影堆叠。
4. **舒服、自然、好用。** 布局、交互、动效都遵循 macOS 的习惯，用户不需要学习。

## 2. 现状的问题

| 问题 | 现状 |
|---|---|
| 管理界面是主角 | 窗口左侧常驻 176 pt 的侧栏，客机画面只是其中一个页面，打开应用先看到的是状态卡片 |
| 客机画面不贴合窗口 | 客机分辨率固定为 1600×1000，窗口比例不同时四周留黑边 |
| 导航分成两套 | 侧栏有 4 个入口加 5 个子项；「设置」是另一套界面，有自己的侧栏和「返回工作台」，里面还有 10 个分组 |
| 相关功能分散 | 时区在侧栏有一页，「设置 → 时区与语言」又有一页；输入法、账户在「虚拟机管理」下，键盘在「设置 → 通用」里 |
| 常用开关藏在菜单里 | 「共享剪贴板」「用 Mac 输入法打字」只在「文件」菜单里 |
| 上限写死 | 拖入最多 50 个、单个 8 GB；复制最多 100 项、合计 8 GB；都不能调 |
| 提示依赖侧栏 | 操作结果以气泡形式从侧栏的图标弹出，侧栏收起后就没有位置显示 |
| 配色 | 暖色纸张底加赤陶色，只有浅色 |

## 3. 方案比较

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| A. 单窗口两种状态（采用） | 同一个窗口在「桌面」和「控制中心」之间切换。桌面状态下客机画面占满窗口；控制中心状态下出现侧栏和管理页面 | 最接近「就是一台电脑」的感觉；沿用现有的窗口和页面机制，风险低 | 看管理页面时看不到完整的客机画面 |
| B. 独立的设置窗口 | 客机窗口只放画面，管理界面放到另一个窗口 | 最符合 macOS 惯例，可以边看客机边调设置 | 需要第二个网页容器和窗口管理，改动大；两个窗口的状态同步容易出错 |
| C. 只换配色 | 保留现有布局，替换颜色 | 最省事 | 客机仍然不是主角，不满足目标 1 |

采用 A。B 可以在 A 完成后，作为「把控制中心拆成独立窗口」的后续选项。

## 4. 窗口结构

### 4.1 工具栏

窗口顶部是一条 40 pt 高的工具栏，和标题栏合为一体，两种状态下都在：

- 左：红黄绿按钮，控制中心开关。
- 中：状态胶囊，内容是「状态点 + 客机名 + 一句状态」，例如「● macOS 客机 · 已保护」。点开是一个浮层，列出网络保护、出口、磁盘三项和对应的操作。
- 右：传文件、全屏、更多（重启、停止、关于这台客机）。

状态点的颜色全应用统一：蓝色是处理中，绿色是正常，琥珀色是需要留意，红色是出错，灰色是已停止。

### 4.2 桌面状态（默认）

- 工具栏以下全部是客机画面，没有侧栏，没有边距。
- 客机分辨率跟随窗口大小，不留黑边（见第 9 节）。
- 全屏时客机占满整块屏幕，成为一个独立的桌面空间，工具栏按 macOS 的惯例自动隐藏，鼠标移到顶部时出现。用四指轻扫或 `⌃←/→` 在 Mac 和客机之间切换，和切换普通桌面一样。
- 全屏时按 `⌃⌘,` 呼出控制中心。它以浮层的形式盖在客机画面上，不退出全屏；再按一次或按 `Esc` 收起。
- 全屏时画面最上沿有一条 2 pt 的蓝色标识线，用来区分客机和 Mac，可以在设置里关掉。
- 操作结果用画面底部居中的浮动提示显示，例如「已把 3 个文件放到「下载」」，约 3 秒后淡出，不打断操作。出错的提示保留到用户关掉。
- 拖文件进来时，画面四周出现蓝色描边，提示可以松手。

### 4.3 控制中心状态

- 点工具栏左侧的开关进入。侧栏从左侧滑入，宽 220 pt，右侧显示管理页面。
- 侧栏顶部是一张客机卡片：状态、客机名和「回到桌面」。再点一次开关也回到桌面。
- 客机没有启动、还没安装或出错时，应用自动停在控制中心的「概览」页，因为这时没有画面可看。

### 4.4 启动

- 打开 VMac 后自动启动客机，并直接进入桌面状态。这一项可以在「通用」里关掉。
- 启动过程中，画面区域显示一个安静的启动页：图标、四步进度（启动虚拟机、连接客机、网络检查、打开桌面）和当前这一步的文字。完成后淡入客机画面。
- 解锁页和首次安装向导使用同一套视觉，内容居中成一列。

## 5. 页面组织

控制中心的侧栏分三组，共 10 项，取代现在的两套导航。

| 分组 | 页面 | 内容 |
|---|---|---|
| — | 概览 | 这台客机的状态和主要操作（启动、重启、停止、回到桌面）；网络保护、出口、磁盘三项摘要，点击进入对应页面 |
| 这台客机 | 虚拟机与磁盘 | 虚拟机列表、切换和新建；当前客机的 CPU、内存、磁盘容量和清理空间 |
| 这台客机 | 账户与系统 | 客机账户、密码、管理员权限；时区与语言；输入法；键盘；客机外观（壁纸和强调色） |
| 这台客机 | 共享与传输 | 共享剪贴板、拖放文件、用 Mac 输入法打字三个开关；共享文件夹；文件大小和数量上限（见第 8 节） |
| 网络 | 代理线路 | 出口节点、订阅、出口策略 |
| 网络 | 环境检测 | 隔离报告、网关检测、Claude 检测、网络连通 |
| VMac | 通用 | 打开时自动启动客机；关闭时关机还是挂起；全屏标识线；更新 |
| VMac | 账户与安全 | VMac 账户、密码保险箱、远程连接 |
| VMac | 环境与恢复 | 环境与恢复、已归档会话 |
| VMac | 关于 | 版本和许可 |

旧入口和新位置的对应关系：

| 旧位置 | 新位置 |
|---|---|
| 侧栏：客机桌面 | 桌面状态；状态卡片移到「概览」 |
| 侧栏：存储空间、虚拟机切换 | 虚拟机与磁盘 |
| 侧栏：客机账户、时区、输入法 | 账户与系统 |
| 侧栏：代理管理 | 代理线路 |
| 侧栏：环境检测 | 环境检测 |
| 设置：账户、密码保险箱、远程连接 | 账户与安全 |
| 设置：通用 | 键盘部分到「账户与系统」，其余到「通用」 |
| 设置：外观 | 通用（保留字号等选项；VMac 始终是浅色，主题切换和自定义主题编辑器在 VMac 里不再显示） |
| 设置：网络与代理 | 代理线路 |
| 设置：时区与语言 | 账户与系统 |
| 设置：环境与恢复、已归档会话 | 环境与恢复 |
| 设置：关于 | 关于 |
| 文件菜单：共享剪贴板、用 Mac 输入法 | 共享与传输（菜单项保留，两处同步） |

所有现有功能都保留，只改变位置和呈现方式。

## 6. 视觉规范

### 6.1 颜色

颜色取自 DeepSeek 网页当前使用的色值。只用它的配色，不使用它的标志和名称。

| 用途 | 色值 |
|---|---|
| 页面底色 | `#FFFFFF` |
| 侧栏、工具栏底色 | `#F9FAFB` |
| 分组底色、输入框底色 | `#F1F3F5` |
| 浮层、弹窗底色 | `#FFFFFF` |
| 分隔线 | 黑色 8% |
| 主要文字 | `#0F1115` |
| 次要文字 | `#61666B` |
| 辅助文字 | `#81858C` |
| 强调色（图标、指示、焦点环） | `#3964FE` |
| 实心按钮底色，悬停 / 按下 | `#3964FE`，`#2F56E8` / `#2648CC` |
| 蓝色文字（链接、选中的导航项） | `#2648CC` |
| 强调色浅底（选中的导航项、提示） | `#E4EDFD` |
| 悬停底色 | `rgba(38,49,72,.06)` |
| 正常 | 圆点 `#22C55E`，文字 `#15803D` |
| 留意 | 圆点 `#F59E0B`，文字 `#B45309` |
| 出错 | 圆点 `#F25A5A`，文字 `#B91C1C` |

规则：

- 蓝色只用于一个页面里最主要的操作、链接、选中状态和焦点环。一页最多一个蓝色实心按钮。
- 正文文字和底色的对比度不低于 4.5:1。白字在 `#3964FE` 上约为 4.7:1。蓝色文字单独用一档更深的蓝，保证在灰色分组和蓝色浅底上也达标。
- VMac 始终是浅色，不跟随系统的深色模式。原生侧栏、工具栏和网页内容用同一份色值。
- 应用内的 VMac 标志由赤陶色改为强调蓝；应用图标改为白底蓝色标志。

### 6.2 字体与字号

系统字体（SF Pro、苹方），数字使用等宽数字。

| 用途 | 字号 / 字重 |
|---|---|
| 页面标题 | 22 / 600 |
| 分组标题 | 13 / 600，次要文字色 |
| 正文、行标题 | 14 / 400 |
| 说明文字 | 12.5 / 400，次要文字色 |
| 按钮、导航 | 13 / 500 |

### 6.3 形状与间距

- 间距以 4 为基数：4、8、12、16、24、32。
- 圆角：分组和卡片 12，按钮和输入框 8，小标签 6，状态胶囊和开关为全圆角。
- 默认不用阴影。只有浮层、弹窗和浮动提示有一层柔和的阴影。
- 管理页面的内容居中成一列，最宽 720，左右留白随窗口变化。

### 6.4 组件

全部页面只用下面这一套组件，替换现在各页面各自的卡片样式：

- **分组列表**：一个圆角分组里放若干行，行与行之间是分隔线。每行左边是标题和一行说明，右边是控件或当前值。这是管理页面的基本形态，和 macOS「系统设置」一致。
- **按钮**：主要（蓝色实心）、次要（浅灰底）、文字按钮、危险（红色文字，确认时为红色实心）。高度 32。
- **开关、下拉、分段控件、步进输入**：尺寸和手感与 macOS 原生控件接近。
- **状态标签**：圆点加文字，颜色含义见 4.1。
- **浮动提示**：桌面状态下的操作反馈。
- **浮层和确认弹窗**：从触发位置展开；危险操作的确认弹窗写明后果，默认焦点在「取消」。
- **空状态和加载**：空状态写明这里是什么、下一步做什么；加载用骨架占位，内容出现时不跳动。

## 7. 交互与动效

### 7.1 交互

1. **键盘留给客机。** 桌面状态下，除下面两个以外的所有快捷键都直接交给客机，和在真机上一样。VMac 自己只占用 `⌃⌘F`（全屏）和 `⌃⌘,`（控制中心）。
2. **改动立即生效。** 开关和选项一改就生效，不设「保存」按钮。需要重启客机才生效的，在这一行下面写明，并提供「现在重启」。
3. **状态始终可见，但不打扰。** 工具栏的状态胶囊随时反映客机状态。日常反馈用浮动提示，只有需要用户做决定时才弹窗。
4. **不可用时说明原因。** 控件不可用时，在旁边用一句话说明原因和怎么解决，例如「启动客机后可查看」。
5. **出错时给出下一步。** 错误信息写清发生了什么和可以怎么做，并尽量带一个能直接点的操作。
6. **窗口有记忆。** 记住窗口的大小、位置，以及上次停在控制中心的哪一页。

### 7.2 动效

动效只用来说明「东西从哪来、到哪去」，不做装饰。

| 场景 | 动效 | 时长 |
|---|---|---|
| 悬停、按下、开关 | 颜色和位置过渡 | 120 ms |
| 侧栏滑入滑出、页面切换、浮层展开 | 位移加淡入 | 200 ms |
| 桌面与控制中心切换、启动页到客机画面 | 淡入淡出，画面由 98% 放大到 100% | 320 ms |
| 处理中 | 状态点缓慢呼吸，进度条平滑推进 | 持续 |

全部使用同一条缓出曲线 `cubic-bezier(.2,.8,.2,1)`。系统开启「减弱动态效果」时，位移和缩放全部改为淡入淡出。

## 8. 共享与传输设置

把现在写死的上限改成可以在「共享与传输」里调整。

| 设置 | 默认 | 可选 |
|---|---|---|
| 共享剪贴板（文字、图片和文件） | 开 | 开、关 |
| 拖放文件 | 开 | 开、关 |
| 用 Mac 输入法在客机中打字 | 开 | 开、关 |
| 单个文件大小上限 | 8 GB | 2、8、32、64 GB |
| 一次最多传输的项数 | 100 | 50、100、500、1000 |

要点：

- 拖入和复制粘贴共用同一组上限。现在拖入是 50 个、复制是 100 项，统一为一个值。
- 上限目前分别写在 Mac 端窗口代码、后台和客机组件三处。改为由后台保存一份，另外两处向它读取，保证三处一致。
- 不提供「不限制」。传输时文件会先在 Mac 上暂存一份，再写入客机，过大的文件可能占满磁盘。改为在传输前检查 Mac 和客机的剩余空间，空间不够时直接说明还差多少。
- 文字和图片的剪贴板大小上限属于传输协议的保护值，不开放调整。

这一部分涉及 Mac 端、后台和客机组件三处，作为独立的一期实现，届时单独写出实现细节。

## 9. 客机画面跟随窗口

现在客机画面的自动调整是关闭的（`automaticallyReconfiguresDisplay = NO`），分辨率固定。打开后，调整窗口大小或进入全屏时，客机会像外接显示器换了分辨率一样重新排布，不再有黑边。

这一项有风险：侧栏滑入滑出会改变画面区域的大小，可能让客机反复调整分辨率。所以先做一次验证：

- 控制中心出现时，客机画面被页面盖住，画面区域的大小保持不变，不触发调整。
- 验证窗口缩放、全屏、多显示器三种情况下客机是否稳定。
- 如果不稳定，保留固定分辨率，改为等比缩放并把四周填成页面底色，使黑边不显眼。

这一项也作为独立的一期，放在最后。

## 10. 分期

界面之外的功能（视觉锚点、共享文件夹、音频、挂起恢复）和整体顺序见 [路线图](2026-11-20-vmac-native-experience-roadmap.md)。下面是界面部分的四期，每一期结束都能打包成一个可用的版本。

| 期 | 内容 | 结果 |
|---|---|---|
| 1. 视觉基础和外壳 | 颜色、字体、组件；原生侧栏和工具栏；桌面与控制中心两种状态；浮动提示；启动页；标志和图标 | 整个应用换成新外观和新结构 |
| 2. 页面重组 | 按第 5 节重排导航，合并旧「设置」；用新组件重做各页面、解锁页和安装向导 | 所有页面完成重做 |
| 3. 共享与传输 | 第 8 节的设置页和可调上限 | 上限可以自定义 |
| 4. 画面跟随窗口 | 第 9 节 | 客机画面贴合窗口 |

## 11. 验证

- 每一期：`ui` 的 lint 和测试通过，Swift 类型检查通过，打包后签名和三项资源校验通过。
- 用模拟的后台数据渲染每个页面的各种状态（已停止、启动中、就绪、出错；窄窗口），逐页核对布局。
- 在真机上走一遍主要流程：打开应用到看到客机画面、进出控制中心、拖入和拖出文件、复制粘贴、修改每一项设置、全屏。
- 对比度按 6.1 的要求检查；开启「减弱动态效果」后检查动效。

## 12. 不做的事

- 不改动隔离、代理、检测等功能本身的行为，只改它们的界面。
- 不做独立的设置窗口（方案 B）。
- 不改 Windows 和 Linux 客机相关的界面，它们不在 VMac 这个版本里。
- 不引入新的界面框架或组件库。

## 修订：第三版视觉（参照 Modern Web Guidance）

第二版在真机上显得沉闷：大块灰底卡片、旧「设置」的表单和新卡片各说各话、页面宽窄不一。第三版按 GoogleChrome/modern-web-guidance 里和界面有关的准则重画了控制中心的网页部分，原生侧栏和工具栏不变。

- **一种容器。** 所有内容都放在白色卡片里：一像素细线、14 像素圆角、极浅的阴影。灰色只用于小块（图标底、分段控件的轨道）。卡片的标题是卡片里的第一行；只有一组内容的页面不再重复标题。
- **一栏。** 十个页面同为 720 宽，代理线路和环境检测不再加宽。
- **标题随页面滚动。** 窗口已有工具栏，网页里不再放第二条吸顶栏。
- **文字。** 字号一律用 rem，跟随「文字大小」设置；标题用 `text-wrap-style: balance`，正文用 `pretty`，说明文字不超过 60 个字符宽。
- **控件用平台自己的。** 开关是 `<input type="checkbox" switch>`，在 WKWebView 里就是系统开关；不支持的环境退回到样式画的开关。下拉用原生菜单。输入框的边线对白底保持 3:1，卡片的细线只是装饰。
- **状态不只靠颜色。** 圆点旁边总有文字；出错条带图标。
- **动效。** 只动透明度和变换；所有位移都乘以 `--vm-move`，减弱动态效果时它是 0，只剩淡入淡出，不再全局把时长压成 0.01 毫秒。页面切换用 View Transition 做交叉淡化。循环动画只在允许动效时运行。
- **少用到的内容收起来。** 账户页里的改密码、恢复密钥、登录与解锁用 `<details>` 折叠；「环境与恢复」拆成一张张卡片。
- **强制颜色模式。** 细线和控件边线改用系统颜色。

概览改为一张客机卡片（状态、名称、一句说明、操作）加三行状态列表；启动进度只在启动期间显示。「通用」里的显示设置改成原生的行：文字大小、指针光标、字体平滑、减少动态效果。
